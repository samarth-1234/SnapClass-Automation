# 🎓 SnapClass — AI-Powered Smart Attendance System

**Smart Attendance. Simple Verification. Better Classrooms.**

SnapClass is an AI-powered attendance management system for schools and colleges. It uses face and voice recognition to simplify attendance and reduce manual effort.

## 🎯 Problem Statement

* Manual attendance takes time.
* Human errors can affect attendance records.
* Managing attendance manually can be difficult.
* SnapClass aims to make attendance faster and easier.

## ✨ Key Features

* **Teacher Portal:** Teacher registration and login.
* **Student Portal:** Student registration and verification.
* **Face Recognition:** Verify identity using a photograph.
* **Voice Recognition:** Verify identity using a voice recording.
* **Flexible Verification:** Face and voice can be used independently.
* **Subject Management:** Organize subjects and enroll students.
* **Digital Attendance:** Store attendance records in Supabase.

## ⚙️ How It Works

1. Register teachers and students.
2. Enroll students in subjects.
3. Verify identity using face or voice recognition.
4. Click **Mark Attendance** after successful verification.
5. Attendance records are saved to Supabase.

## 🛠️ Technology Stack

* **Language:** Python
* **Frontend:** Streamlit
* **Face Recognition:** dlib, face_recognition_models
* **Voice Recognition:** Resemblyzer, librosa
* **Machine Learning:** scikit-learn
* **Data Processing:** NumPy, Pandas
* **Database:** Supabase
* **Other Libraries:** Pillow, Segno, bcrypt

## 🧠 AI/ML Implementation

* Face recognition uses facial processing and embeddings.
* Voice recognition uses voice embeddings generated by Resemblyzer.
* Embeddings help verify student identity.
* Either verification method can be used independently.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/samarth-1234/SnapClass-main.git
   ```
2. Open the project folder:

   ```bash
   cd SnapClass-main
   ```
3. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
5. Configure your Supabase credentials in `.streamlit/secrets.toml`. Never commit real credentials.
6. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

## 🔐 Security & Privacy
